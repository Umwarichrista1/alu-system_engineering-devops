# ssh

Project on SSH: creating a key pair, connecting to a remote server with it,
and configuring the SSH client.

| File | Description |
|------|-------------|
| `0-use_a_private_key` | Connects to the server as ubuntu using `~/.ssh/school` |
| `1-create_ssh_key_pair` | Creates a 4096-bit RSA key pair named school |
| `2-ssh_config` | SSH client config: use `~/.ssh/school`, no password login |
