# web_server

Scripts that configure an Ubuntu web server with nginx.

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server with scp |
| `1-install_nginx_web_server` | Installs nginx and serves a Holberton School page |
| `2-setup_a_domain_name` | Contains my domain name |
| `3-redirection` | Adds a 301 redirect for /redirect_me |
| `4-not_found_page_404` | Adds a custom 404 page |
| `5-design_a_beautiful_404_page.html` | My own designed 404 page |
